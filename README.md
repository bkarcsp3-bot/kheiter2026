# تطبيق متابعة الغيابات ونسب المشاركة — بلدية الخيثر (2026)

تطبيق ويب مبني بـ **Flask** لمتابعة حضور وغياب المؤطرين ورصد نسب المشاركة في الفترات المعتمدة (**09:30**، **14:00**، **17:00**، **19:00**) عبر مراكز ومكاتب التصويت ببلدية الخيثر (ولاية البيض) ليوم الاقتراع **28 نوفمبر 2026**.

## هيكل المشروع
- `app.py`: منطق التطبيق والمسارات والواجهات وتصدير تقارير CSV.
- `init_db.sql`: مخطط قاعدة البيانات والبيانات الأولية للمراكز والمؤطرين.
- `templates/`: قوالب الواجهات (`base.html`، `login.html`، `center_dashboard.html`، `admin_dashboard.html`).
- `static/img/authority_logo.svg`: الشعار المستخدم في الواجهة.
- `requirements.txt`، `Procfile`، `runtime.txt`: ملفات التشغيل والنشر السحابي.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح المتصفح على: `http://127.0.0.1:5000`

## الرفع على GitHub والنشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع جديد على GitHub.
2. أنشئ **Web Service** على منصة Render واربطه بالمستودع.
3. تأكد من أن أمر التشغيل هو `gunicorn app:app`، واضبط متغيرات البيئة `SECRET_KEY` و`ADMIN_PASS` عند الحاجة.
